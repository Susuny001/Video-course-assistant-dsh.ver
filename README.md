我们要做的就是：一个exe，说白了就是高级的网课播放器。用户可以上传一个视频，或者预先让软件读取，然后需要做字幕，双语。字幕需要以另一种形式存到机器里，并且还要默认把视频分成几段，每一段的内容写出来abstract，用户可以指定语言，或者仅专业名词用英语之类的，并且详细内容需要给到内部的答疑AI（可以接API或者自己弄，以下同理），分段的进度条之类的别让我说。细节做好了，别他妈让我看个字幕都看不好，这种小问题。用户可以自己选中某一段到某一段给内置AI，然后内置AI会阅读**录音**和视频画面内容，因为有时候录音有错的。录音让语音模型识别出来之后不是没了，是还得让文本模型、视觉模型结合课堂视频内容，再看他讲的什么，把录音不行的地方修好。这样最后的才是给答疑模型的。答疑模型的选择跟gpt聊天界面一样，什么都能选，别简单的慢吞吞的，要思考的时候又不思考。这些模型用户可能不会，自己找免费的API给他们接上。有条件的直接给提供点击下载安装连接到这个软件的bat，一点全部执行完，也别让用户挂到前台一直等，纯神经病，我都懒得说这细枝末节，不是我不说你就不做。这玩意你自己用着都不顺手就别给我。每做一个功能/部分再commit，别几把一直不commit，也不一点就commit。给用户多接口也别把界面操作写太丑。
